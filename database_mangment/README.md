# Database Management Tools

## adminer
Adminer 是一个基于 PHP 的数据库管理工具，支持多种数据库，包括 PostgreSQL、MySQL、SQLite 等。它提供了一个简单的界面，用户可以方便地连接和管理数据库。

- 管理页面访问: http://localhost:8080
- 数据库连接信息:
  - 数据库类型: PostgreSQL
  - 数据库主机: postgres
  - 数据库端口: 5432
  - 数据库名称: postgres
  - 数据库用户名: postgres
  - 数据库密码: 123456

如果需要连接Elasticsearch，Mongodb数据库，需要安装driver插件。


  ## redisinsight
  Redis Insight 是一个基于 Redis 的数据库管理工具，支持 Redis 数据库的监控、分析和管理。它提供了一个简单的界面，用户可以方便地连接和管理 Redis 数据库。

  - 管理页面访问: http://localhost:8001
  - 数据库连接信息:
    - 数据库主机: redis
    - 数据库端口: 6379
    - 数据库用户名: default
    - 数据库密码: 123456
